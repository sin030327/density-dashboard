# 권역 건축밀도 · 가용공간 대시보드

OpenStreetMap(Overpass API) 데이터로 대상지 반경 내 건축밀도를 분석하는 단일 페이지 웹 대시보드입니다.

## 기능

- **대상지 정의** — Nominatim 지오코딩 검색, 좌표 직접 입력, 지도 클릭, 중심 마커 드래그
- **① 건물 용도 구성 · 기재율** — OSM `building` 태그를 6개 대분류로 재분류, 미분류(태그 미기재) 비율 표시
- **② 링(권역)별 밀도표** — 링 면적으로 나눈 건물 밀도 · 건폐율 · 용적률 비교
- **③ 스마트공원 요소 우선순위** — 효과 × 난이도 매트릭스 (수정 내용은 브라우저에 저장됨)
- **④ 산출물 내보내기** — 조회일시·출처·쿼리 원문이 기록된 ZIP / CSV / README.md / GeoJSON
- **심화 분석** — 개발 가용 용적 추정, 버제스 동심원 · 호이트 섹터 · 해리스-울만 다핵심 이론 검증

## 실행

배포된 주소로 접속하면 바로 동작합니다.

로컬에서 열 때는 `대시보드 실행.bat`을 더블클릭하세요. HTML 파일을 직접 열면(`file://`) 브라우저가 `Origin: null`을 보내 Overpass 서버가 요청을 거부하므로 분석이 실패합니다. 이 배치 파일은 별도 설치 없이 윈도우 기본 PowerShell만으로 현재 폴더를 `http://localhost`로 서빙합니다.

## 데이터 출처 · 한계

- 데이터: © OpenStreetMap contributors (ODbL 1.0) · Overpass API · Nominatim
- OSM 건물 태그 기반 **추정치**이며 실제 인허가 용적률·건폐율(지자체 조례, 용도지역 등)과 다를 수 있습니다.
- 층수 태그가 없는 건물은 설정한 기본 층수로 가정해 연면적을 계산합니다.
- 도시공간구조 이론 분석은 단순 기하학적 근사이므로 계획 검토용 참고자료로만 사용하세요.
